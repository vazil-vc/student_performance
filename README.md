# Student Performance Prediction

A Machine Learning web application built using Streamlit that predicts a student's exam score based on academic, personal, and environmental factors.

## Features

- Student score prediction
- Linear Regression model
- Data preprocessing
- One-hot encoding
- Feature scaling
- Streamlit user interface

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib
